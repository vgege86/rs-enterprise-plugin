# Dependencias Python del servidor MCP rs-workspace (mcp/rs-workspace-server.py).
#
# FastMCP se importa como `from mcp.server.fastmcp import FastMCP`; lo aporta el paquete `mcp`
# (SDK oficial de Model Context Protocol). Piso de versión conservador: a partir de 1.2.0 el
# submódulo `mcp.server.fastmcp` es estable. Instalar con: pip install -r requirements.txt
#
# ⛔ Tope superior <2: el major mcp 2.0.0 ELIMINÓ `mcp.server.fastmcp` (ImportError en el server y en
# los tests). El plugin usa la API FastMCP de la línea 1.x; sin este tope, `pip install` arrastra 2.x
# y rompe tanto el runtime del server como el CI. Subir a 2.x exige migrar el import de FastMCP.
#
# El resto de herramientas (sqlplus, sqlcmd, svn, git, dotnet, msbuild/vswhere) son CLIs externas
# del sistema, no paquetes Python — se comprueban en runtime (_check_svn_cli/_check_git_cli).
mcp>=1.2.0,<2

# Dev/test: tests unitarios de las funciones puras del MCP (tests/test_mcp.py). Solo para CI/desarrollo,
# no lo necesita el runtime del server. Tope superior conservador para no arrastrar un major nuevo.
pytest>=7.0,<9
